# OsonEats — фронтенд витрины

Витрина доставки еды и раздел «Куда сходить» для Худжанда и Душанбе.
Next.js 15 (App Router) + React 19 + TypeScript. Стили — обычный CSS с токенами (`app/globals.css`), перенесён один в один из утверждённых макетов.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run typecheck
```

## Структура

```
app/                  страницы (App Router)
  layout.tsx          шапка, нижнее меню, плашка корзины, шрифт Rubik, тема без вспышки
  page.tsx            главная
  globals.css         токены (цвета, радиусы) и стили всех экранов
components/           UI-компоненты (Header, TabBar, VenueCard, DishCard, ...)
  AppProvider.tsx     клиентское состояние: режим, тема, корзина, избранное (localStorage)
lib/
  data.ts             моковые данные: заведения, меню, места. Заменить на API
  utils.ts            поиск блюда/заведения, часы работы, форматирование телефона
```

## Данные

Сейчас всё берётся из `lib/data.ts`. Меню «Панды» — реальные названия и цены с osoneats.com,
остальное и все фото блюд (TheMealDB) — заглушки. Формы типов (`Venue`, `Dish`, `Place`) —
это контракт, который должен отдавать бэкенд.

## Бэкенд

Все запросы к серверу собраны в `lib/api.ts`. Без переменной `NEXT_PUBLIC_API_URL` они работают
в демо-режиме (любой SMS-код, кроме 0000). Ожидаемые эндпоинты:

| Метод | Путь | Тело | Ответ |
|---|---|---|---|
| POST | `/auth/sms` | `{ phone: "+992901234567" }` | 200 |
| POST | `/auth/verify` | `{ phone, code }` | `{ ok: boolean }` + cookie сессии |
